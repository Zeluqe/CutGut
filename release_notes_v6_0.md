## ✂️ CutGut 202608240-6-0 — Fala 6: Wielki Redesign Windows 11 / Fluent UI

Głęboka przebudowa wizualna w nowoczesnym, przejrzystym stylu **Windows 11 / Fluent Desktop**: miękkie grafitowe karty, elegancka hierarchia, zaokrąglenia 8-10px, ciemny pasek tytułowy DWM oraz zbalansowany układ eksportu i oceny jakości.

---

### 🌟 Kluczowe nowości i zmiany wizualne w `202608240-6-0`:

1. **🎨 Estetyka Windows 11 Fluent UI**:
   - **Nowoczesna paleta Dark Graphite** (`#141416` / `#1c1c1f`) z subtelnym 1px obramowaniem i miękkimi cieniami.
   - **Natywny ciemny pasek tytułowy Windows (DWM)** i zaokrąglenia okna.
   - Usunięto natłok przypadkowych emoji z każdego przycisku na rzecz czystej, eleganckiej typografii `Segoe UI Variable` i spójnych ikon akcji.
   - Wyraźna hierarchia: **Główny przycisk akcji** `[ ✂ Przytnij i kompresuj ]` w charakterystycznym niebieskim kolorze Windows (`#0078d4`), a przycisk `[ Anuluj ]` bezpiecznie wygaszony do momentu startu kodowania.

2. **⏱️ Zaawansowany Fluent Timeline (`FluentTimelineWidget`)**:
   - Wyraźniejsza ścieżka czasu z zaznaczonym zakresem w półprzezroczystym błękicie Fluent.
   - Wizualny zielony znacznik **IN** i czerwony **OUT** z możliwością przeciągania myszką.
   - Płynny kursor Playhead (`#60cdff`) oraz **pływający dymek czasu (tooltip)** podczas najechania i przewijania.
   - Pływające, dyskretne powiadomienia Toast (np. `Początek (IN) ustawiony: 00:12.35`, `Zapisano klatkę PNG`).

3. **📊 Zbalansowany układ 2-kolumnowy**:
   - **Lewa karta (Konfiguracja eksportu)**: Profile społecznościowe (Discord 20MB, Nitro 50MB, Shorts HQ 9:16), proporcje kadru, szybkie wyrównanie `[ ◀ Lewo ] [ 🎯 Środek ] [ Prawo ▶ ]` oraz selektor enkodera GPU.
   - **Prawa karta (Jakość i parametry)**: Pigułka statusu jakości (`● Świetna jakość`), rozdzielczość, FPS, bitrate, przewidywany rozmiar pliku oraz przycisk `[ 🔬 Sprawdź próbkę jakości ]`.

4. **📋 Płynna szuflada kolejki zadań (Queue Drawer)**:
   - Zintegrowany, nowoczesny panel kolejki wsadowej z tabelą zadań, paskami postępu i szybkim otwieraniem porównania A/B.
